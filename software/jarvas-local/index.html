The same local Jarvas concept framed as the lower-cost flash-drive version for buyers who want the smallest hardware footprint and still want offline use.

What users need: Windows 10 22H2+ and Python 3.11+. This build starts its own private Ollama runtime, so users do not need to preinstall the Ollama app.
Quick start: Unzip the download, then double-click Jarvas-Install-and-Run.bat. On the first run it will reuse any shared cache already on the machine, or download the required Ollama runtime/model once if needed.
Offline note: Once the bundle is installed, the intended use case is completely offline local AI for remote work and private use. The only exception is a first-run fetch if the shared runtime/model is not already cached on that machine.
